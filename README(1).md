# CatatUang — Pencatatan Keuangan Pribadi

Next.js 14 (App Router) + Tailwind CSS + Lucide. Data disimpan di LocalStorage browser, tanpa login dan tanpa backend.

## Jalankan lokal
```bash
npm install
npm run dev   # http://localhost:3000
```

## Deploy ke Vercel
1. Push folder ini ke repositori GitHub.
2. Buka https://vercel.com/new, impor repositori tersebut.
3. Framework terdeteksi otomatis (Next.js). Klik **Deploy**. Tidak ada environment variable.

Atau via CLI: `npm i -g vercel && vercel --prod`.
